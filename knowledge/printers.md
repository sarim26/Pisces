# Printer issues

Keywords: printer, print, printing, toner, paper jam, spooler, cartridge

## Symptom: Printer will not print
1. Confirm the printer is powered on and shows a ready status.
2. Confirm the job is sent to the correct printer queue.
3. Check paper tray and toner/ink levels.
4. Restart the Print Spooler service on the workstation:
   - Windows: Services → Print Spooler → Restart
5. Clear stuck jobs from the print queue, then send a test page.
6. If the printer is networked, ping the printer IP. If ping fails, check cable/Wi-Fi and the printer network settings.

## Symptom: Paper jam
1. Power off the printer.
2. Open all access panels and remove jammed paper in the paper path direction (do not pull backwards if it tears).
3. Close panels, power on, and print a test page.
4. If jams repeat, inspect rollers for wear and schedule hardware service.

## Symptom: Toner/ink empty or poor quality
1. Replace the cartridge with the approved model for that printer.
2. Print a nozzle/alignment test if quality is still poor.
3. Do not mix third-party cartridges unless approved by IT.

Escalate to a technician if the printer is offline on the network after a reboot, hardware error lights persist, or the device needs parts.
