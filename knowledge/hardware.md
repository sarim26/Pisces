# Hardware and equipment assets

Keywords: hardware, equipment, asset, laptop, desktop, monitor, keyboard, mouse, disk, ram, cpu

Covers in-house IT assets that may have a hardware problem.

## Symptom: Device will not power on
1. Confirm the power cable / charger is seated and the outlet works.
2. Try a known-good charger or power lead.
3. For desktops, check the PSU switch and rear cable.
4. If still dead, tag the asset and escalate for hardware diagnosis.

## Symptom: Slow PC or frequent freezes
1. Note the asset tag / hostname.
2. Ask whether it started after a software change or is gradual.
3. Technician checks disk health, RAM, and event logs.
4. Do not tell the user to open the chassis.

## Symptom: Peripheral not working (keyboard, mouse, monitor)
1. Reseat the cable / try another USB port.
2. Test the peripheral on another PC if available.
3. If the device is dead, replace from stock and log the asset.

Escalate when the fault is physical damage, warranty replacement, or parts are required.
